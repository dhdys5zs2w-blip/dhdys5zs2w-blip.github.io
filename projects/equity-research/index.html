How the model works

Prices and volume in, a ranked list out, every evening. Nothing here uses fundamentals, and the model has never been refit.

  1. UniverseEach month, the 500 most-traded US stocks by 20-day median dollar volume — including names that later delisted, because dropping them would flatter every historical number.
  2. Signals19 technical indicators computed from price and volume only (25 built, then pruned by correlation). There are no fundamentals anywhere in this system.
  3. Frozen modelA gradient-boosted model trained once, on 2005–2015, and never refit — on purpose. The live record is only meaningful because the map is held still while reality is compared against it.
  4. Ranking and bookEach evening every name the model can score (up to ~500) is ranked best to worst. The top tenth — typically 49 names — forms an equal-weight, long-only paper book with a 30% buffer: a name enters in the top tenth and is not sold until it drops out of the top 30%, so a typical name is held several days and turnover roughly halves.
  5. Live recordThe book is logged append-only before the outcome exists, and evaluated on next-day returns. A day scored in arrears is marked backfill and never counts as evidence.
What the model keys on, and how big the edge really is

What the model keys on is not fast timing. Feature attribution puts about 34% of its importance on ATR% (realized volatility) and 28% on distance from the 200-day moving average — it conditions on a stock's volatility-and-trend state.

Be blunt about scale: the claimed edge is a few basis points per day, which on a $100k book is roughly tens of dollars a day before trading costs. The backtests support it — and show that it is earned overnight, not during the session, and that it carries into the following night, so an execution one day behind the signal keeps it. The live record, which is the only test that can't be gamed, has barely begun.

Glossary
  • Excess return — a stock's return minus its sector median, centered so each day's full cross-section averages zero.
  • bps — basis points; 1 bp = 0.01%, so 100 bps = 1%.
  • SE — standard error; roughly, ±2 SE spans the plausible range around an estimate.
  • Independent block — a stretch of adjacent days counted as one observation, since days overlap.
  • IC — rank correlation between model ranking and realized outcomes.
  • Decile — one tenth of that day's scored names; roughly 30–50 stocks here.
  • Frozen model — fitted once on 2005–2015, never updated; every later day is out-of-sample.
  • Live vs backfill — live: scored before the outcome existed; backfill: scored in arrears — never evidence.
  • Committed in advance — written before the outcome existed, judged by when the row was written rather than by its stamp. Since 12 September 2026 the live stamp also covers 30 days scored in arrears, so this is the count that carries evidence.
  • Implementable — what a one-day-lagged execution at the open would earn: enter at the next open, exit at the open after. The only return reported as a result. The record internally books a close-to-close return instead, which is an accounting convention, not a strategy.

Does the ranking predict returns?

Every scored name on every scored day, sorted into tenths of the model's rank. If the model orders stocks at all, the bars should rise from left to right — and with about two months of days against an edge of a few bps, noise will dominate for a long time.

How to read this

This chart uses the full scored cross-section — up to ~500 names a day, fewer on reduced-coverage days — not just the book. Each day every scored name with a realized next day falls into a rank decile — the model's least favorite tenth on the left, its favorite tenth on the right — and each bar is the realized next-day excess return in bps, averaged within each day first, then across all scored days, with a block-bootstrap standard error. It is out-of-sample by construction: the model was frozen at end-2015 and scoring began July 2026.

Note which end does the separating: a long-only book only harvests the top decile, so strong separation at the bottom alone — the model's rejects underperforming — would not be captured by this construction. One more caveat: some scored days were recovered in arrears. The scores are deterministic either way, but only evening-of days prove the commitment came before the outcome — the same rule that keeps live and backfill separate everywhere else here.
