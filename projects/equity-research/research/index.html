Each stamp is the verdict word the block's own rule produced, read against the claim it tested: a pass is set in the positive colour, a fail in the negative one. Neutral outcomes — INDISTINGUISHABLE, PARTIAL, VOID, “not detected” — stay uncoloured: they are outcomes, not results, and a void run is not a failure of the hypothesis. A block whose verdicts differ by label is counted under each outcome it carries. “Supports” is a reading of a backtest verdict, never a live result.
